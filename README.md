# Sitio legal público

Esta carpeta está lista para GitHub Pages. En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /docs**.

Después agrega el dominio personalizado `ticketgomx.lat`. GitHub mostrará los registros DNS exactos; reemplaza el URL Redirect de Namecheap por esos registros y espera la propagación.

Las URLs finales serán `https://ticketgomx.lat/terminos.html` y `https://ticketgomx.lat/privacidad.html`.
